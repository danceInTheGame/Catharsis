# HSK Help — projet Flutter

Ce dossier contient le **projet Flutter** de l'application HSK Help.

La documentation complète (présentation, fonctionnalités, prise en main, architecture, fabrication des données, licence) se trouve dans le README à la **racine du dépôt** :

## Démarrage rapide

```bash
flutter pub get
flutter run
```

## Vérifications

```bash
flutter analyze
flutter test
```

## Générer l'APK

```bash
flutter build apk --release
# → build/app/outputs/flutter-apk/app-release.apk
```
